# Builder Standards for Claude (vn-builder-standards)

Created by Soroosh Hedayat
Designed in Collaboration by: VectorNine Systems Inc. & Acid Secs Productions Inc.

When Claude builds an app or game for you, it guesses how things should look. This plugin replaces the guessing with your choices. It asks a few quick questions, one at a time, about icons, buttons, colours and text. Apps and games are asked separately. You can answer "choose for me", or fill in the example sheet yourself.

## What it does
- Saves your look choices so every new screen matches.
- Offers house rules you can switch on or off: a Read aloud button on long text, licence checks if you plan to sell what you build, reusable code with an install note, detailed tick-box guides for jobs you do yourself, and a plain-English summary at the end of each build.

## What it needs
Nothing to install. It reads and writes one small settings file, `Documents\ClaudeSetup\settings.json`.

## What it sends
Nothing.

Switch it on or off with claude-setup-wizard.
